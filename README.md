# Criminal Risk Assessment Request – ODK XLSForm

## Assignment

This project contains an ODK XLSForm developed from the provided Criminal Risk Assessment Request PDF.

## Objective

The objective of this assignment was to convert the provided PDF form into a structured XLSForm that can be used with ODK-compatible tools.

## Work Process

1. Reviewed the ODK XLSForm documentation to understand the structure and working of XLSForms.
2. Reviewed the provided XLSForm reference/sample.
3. Carefully studied the Criminal Risk Assessment Request PDF.
4. Created the XLSForm based on the sections, questions, choices, and requirements in the PDF.
5. Tested the XLSForm using the ODK XLSForm online validator.
6. Identified and fixed errors reported during validation.
7. Tested the form again to ensure that the structure and questions were working correctly.
8. Compared the generated form with the original PDF and made the required modifications.
9. Finalized the XLSForm.

## Files

- `Criminal_Risk_Assessment_Request.xlsx` – Final XLSForm.
- `Criminal Risk Assessment Request pdf.pdf` – Original reference PDF.
- `Sample XLS Form Reference.xlsx` – XLSForm reference provided for the assignment.
